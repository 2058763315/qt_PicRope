# qt_PicRope · 图绳（Qt 重构版）

> **Qt 二次开发版本**，源自作者 [Renly1994](https://github.com/Renly1994) 的[PicRope](https://github.com/Renly1994/PicRope)（Windows 截图暂存与桌面贴图工具）。
> 本仓库使用 **C++ / Qt Widgets** 对原 **C# / WPF** 项目进行重构与二次开发。

**图绳（PicRope）** 是一款 Windows 截图暂存与桌面贴图工具：它把截图自动收集到屏幕
上沿的一条“绳子”上，鼠标移到顶部即展开、离开后自动收起。单击图片即可复制，拖入
聊天框、文档等目标应用即可取用，也可以把图片取下来钉在桌面上对照。适合写文档、
做教程、整理参考图等场景。

## 一、项目来源与说明

- **原作者仓库**：<https://github.com/Renly1994/PicRope>（Windows 截图暂存与桌面贴图工具）
- **本仓库定位**：对原作者 C#/WPF 实现的 **Qt 二次开发版本**，代码用 C++17 重写，
  界面与交互逻辑对齐原版，并复用其功能设计（截图收集、绳子、篮子、信封、桌面贴图、
  托盘、多显示器与主题等）。
- 各源文件头部的注释均已标注与原版模块的对应关系（如 `app.h ↔ App.cs
  DesktopController`、`ui/shelf.h ↔ ShelfWindow`、`core/gallery.h ↔ Gallery` 等），
  便于对照原版理解设计。

> **说明**：二次开发版本目前聚焦于核心“收集 — 挂绳 — 复制/拖拽/贴图”闭环，
> 原版的**内置图片编辑器**与**区域截图标注**（画框/箭头/涂画/马赛克等）尚未在本仓库
> 内实现：当前“编辑”会调用系统默认图片查看/编辑器，区域截图则唤起系统截图工具。

## 二、核心功能

| 功能 | 说明 |
| --- | --- |
| **截图收集** | 自动扫描 Windows 截图文件夹的新图片；支持剪贴板图片、剪贴板文字与手动导入 |
| **挂绳暂存** | 新图片按“自动上绳”开关进入绳上（最近 50 张）或图片篮子；点击托盘可切换 |
| **复制与拖拽** | 单击复制图片，拖入目标应用；滚轮在绳上浏览更多挂图 |
| **桌面贴图** | 单击夹子取下图片、置顶钉在桌面，可拖动、滚轮缩放，点图钉挂回 |
| **图片篮子** | 暂存暂不用的截图，支持多选、大图预览与批量挂绳 |
| **文字信封** | 收集剪贴板文字，支持搜索、查看全文、复制与删除，保留原文换行与缩进 |
| **全局热键** | `Ctrl+Alt+T` 显示/收起；`Ctrl+Alt+S` 唤起区域截图（组合键可自定义） |
| **托盘控制** | 剪贴板图片/文字收集开关、自动上绳、外观主题、打开收集文件夹等 |
| **桌面适配** | 五套外观主题、多显示器选择（跟随鼠标或固定）、顶部自动收起、点击穿透 |

## 三、项目内容框架

### 3.1 目录结构

```
qt_PicRope/
├── main.cpp              入口：字体、单实例锁、状态加载、启动控制器
├── app.h / app.cpp       桌面控制器（AppController）：装配模块、处理动作、
│                         监听剪贴板、绑定托盘与全局热键
├── widget.h/.cpp/.ui     骨架窗口（Qt 自动生成的默认窗口，可忽略）
├── system/               Windows 系统能力封装
│   ├── win32.h/.cpp      全局热键(RegisterHotKey)、多显示器信息、置顶/穿透
│   │                     窗口、光标位置、前台窗口状态检测
│   └── clipboard.h/.cpp  剪贴板读写：图片、文字、文件引用、自有格式标记
├── core/                 核心业务逻辑
│   ├── state.h/.cpp      状态持久化：设置与收藏路径写入 data/state.json
│   ├── image.h/.cpp      图片读取校验、缩略图生成、像素指纹（去重）
│   ├── gallery.h/.cpp    图片收藏管理：挂绳 items + 收集 collected，
│   │                     条目用 QSharedPointer 共享管理
│   ├── texts.h/.cpp      文字收藏（信封数据源）
│   └── capture.h/.cpp    截图收集管线：文件夹扫描、剪贴板收集、去重、
│                         手动导入、收件夹副本管理
├── ui/                   界面层
│   ├── themes.h/.cpp     五套外观主题（经典银灰/棉麻木夹/奶白/柔彩/石墨）
│   ├── shelf.h/.cpp      绳子主窗口：置顶透明窄条、边缘自动展开/收起、
│   │                     非交互区点击穿透、卡片装配
│   ├── card.h/.cpp       单张图片卡片：单击复制、双击打开、长按编辑、
│   │                     右键菜单、拖拽、点夹子贴桌面
│   ├── pinned.h/.cpp     桌面贴图窗口：无边框置顶、拖动、滚轮缩放
│   ├── panels.h/.cpp     图片篮子 + 文字信封（圆角无边框面板）
│   └── tray.h/.cpp       系统托盘菜单与开关
├── resources.qrc         资源清单（app.ico）
├── app.ico               应用图标
└── qt_PicRope.pro        qmake 工程文件
```

### 3.2 三层架构划分

| 层 | 目录 | 职责 | 典型类型 |
| --- | --- | --- | --- |
| 系统层 | `system/` | 与 Windows 平台能力交互：热键、显示器、剪贴板、窗口特效 | `Win32`、`Clip`、`SystemEvents` |
| 核心层 | `core/` | 与界面无关的业务逻辑与数据：状态、收藏、收集、去重 | `StateStore`、`Gallery`、`TextCollection`、`CapturePipeline`、`ImageContent` |
| 界面层 | `ui/` | 所有可见窗口与控件、交互与外观 | `ShelfWindow`、`ShotCard`、`PinnedImageWindow`、`PanelWindow`、`BasketWindow`、`TextsWindow`、`TrayController` |

- **依赖方向**：`ui → core → system`，`core` 不依赖界面，便于复用与测试。
- **装配枢纽**：`AppController`（`app.cpp`）负责把三层粘合——持有各模块实例、
  用信号槽连接“界面动作 → 业务处理”，并监听系统剪贴板与全局热键。

### 3.3 关键设计点

- **共享条目模型**：`Gallery` 用 `QSharedPointer<CaptureItem>` 让“挂绳”与“收集”
  两个列表共享同一对象，卡片与桌面贴图窗口可安全延长条目生命周期，避免悬空指针。
- **剪贴板防回环**：写回剪贴板时带“图绳自有格式”标记，收集逻辑据此跳过自身写入
  的回显；同时用像素指纹（SHA-256 采样）做图片去重。
- **原子持久化**：`state.json` 用 `QSaveFile` 原子写入，图片全部复制进程序旁
  `data/Captures` 收件夹统一管理。
- **单实例与容错**：用 `QLockFile` 保证单实例，崩溃残留锁可清理；启动失败写
  `data/error.log`。

## 四、构建与运行

**环境要求**

- Qt 6（Widgets 模块），支持 C++17 的编译器（MSVC / MinGW 均可；MSVC 已开启 `/utf-8`）
- Windows 10 / 11 64 位

**构建步骤**

```bash
# 用 Qt Creator 打开 qt_PicRope.pro，选择构建套件后直接构建运行；
# 或在命令行 qmake + make 构建：
qmake qt_PicRope.pro
make          # MinGW：mingw32-make；MSVC：nmake / jom
```

**运行目录约定**

- 状态与配置：程序旁的 `data/state.json`（设置、挂绳与收集路径、文字收藏）
- 图片收件夹：程序旁的 `data/Captures/`（收集与手动导入的图片副本）
- 错误日志：`data/error.log`（热键注册失败等异常会记录于此）

**常用快捷键与操作**

| 操作 | 方式 |
| --- | --- |
| 显示 / 收起绳子 | `Ctrl+Alt+T`，或单击托盘图标 |
| 区域截图 | `Ctrl+Alt+S`（唤起系统截图工具，截图结果进入剪贴板） |
| 打开图片 | 双击卡片，使用系统默认图片应用 |
| 复制 / 编辑 | 单击复制；长按或右键 →「编辑」 |
| 桌面贴图 | 单击卡片上的夹子取下；点图钉挂回 |
| 托盘管理 | 剪贴板图片/文字收集开关、自动上绳、外观主题、打开收集文件夹 |
