> **Qt 二次开发版本**，源自作者 [Renly1994](https://github.com/Renly1994) 的 [PicRope](https://github.com/Renly1994/PicRope)（Windows 截图暂存与桌面贴图工具）。本仓库使用 **C++ / Qt Widgets** 对原 **C# / WPF** 项目进行重构与二次开发。

**图绳（PicRope）** 是一款 Windows 截图暂存与桌面贴图工具：它把截图自动收集到屏幕上沿的一条“绳子”上，鼠标移到顶部即展开、离开后自动收起。单击图片即可复制，拖入聊天框、文档等目标应用即可取用；双击可用内置查看器放大查看。适合写文档、做教程、整理参考图等场景。

## 二、核心功能

| 功能 | 说明 |
| --- | --- |
| **截图收集** | 自动扫描 Windows 截图文件夹的新图片；支持剪贴板图片、剪贴板文字与手动导入 |
| **挂绳暂存** | 新图片按“自动上绳”开关进入绳上（最近 50 张）或图片篮子；卡片多时自动交叠排布以适配可视宽度 |
| **复制与拖拽** | 单击复制图片，拖入目标应用（拖拽为复制语义）；右键可「取下」或「批量取下」 |
| **内置查看器** | 双击图片用内置查看器打开：同目录图片 ← / → 切换、滚轮缩放、`0` 缩放复位、Esc 关闭，底栏显示文件名与缩放/序号 |
| **图片篮子** | 按文件名搜索、右键重命名、打开所在文件夹；右键「复制到剪贴板」「用系统默认编辑器打开」「挂上绳子 / 取下绳子」「删除」；双击内置预览，框选或 Ctrl/Shift 多选 |
| **文字笔记** | 收集剪贴板文字（原版称“文字信封”）；支持搜索、查看全文、复制、多选删除，保留原文换行与缩进 |
| **设置界面** | 托盘「设置…」打开，屏幕居中；左右两栏布局：左侧分区导航（点击跳转、滚动时自动高亮），右侧内容可滚动，含 **功能 / 快捷键 / 外观 / 数据 / 其他 / 关于** 六个分区；「快捷键」分区列出全部快捷键（仅「显示 / 收起挂绳」可自定义） |
| **界面语言** | 简体中文 / English 可选，切换后自动重启生效；界面文字经 Qt 翻译文件（`translations/PicRope_en.qm`）加载 |
| **自定义热键** | 显示 / 收起挂绳的全局热键可改（默认 `Ctrl+Alt+T`），须含 Ctrl/Alt/Shift/Win 修饰键；注册失败会提示并自动回滚 |
| **外观调节** | 卡片尺寸 小 / 中 / 大、挂绳不透明度 20%–100%、鼠标离开后收起延迟 300 / 800 / 1200 / 1500 毫秒，改动即时生效 |
| **自动清理** | 设置「功能」中开关；可分别设图片篮子上限（挂绳 + 篮子合计）与文字笔记上限，默认各 200，超出时移除最早收集的内容；上限改到低于当前数量时会先确认 |
| **数据管理** | 导出 / 导入数据备份（Zip，含设置与图片、文字笔记；均异步执行，导出行内显示进度与结果）、存储空间统计（点击展开明细、异步扫描图片 / 文字笔记 / 配置与其它占用）、打开数据目录 |
| **开机自启** | 设置中开关，写入当前用户注册表 Run 项；安装版在向导里勾选的自启也会在此同步显示 |
| **应用内更新** | 启动后静默检查 GitHub 最新发行版，发现新版本询问后自动下载安装包并拉起安装（可在设置中关闭自动检查） |
| **区域截图** | 唤起系统截图工具（`ms-screenclip:`，默认快捷键 `Win + Shift + S`），托盘「更多 → 区域截图…」亦可触发 |
| **托盘控制** | 显示/收起、图片篮子…、文字笔记…、剪贴板图片/文字收集开关、自动弹出、新图片自动上绳、设置、更多（区域截图 / 打开收集文件夹 / 全部取下保留文件）、退出 |
| **多显示器** | 多显示器选择（跟随鼠标或固定）、面板按鼠标所在屏幕呼出、顶部自动收起、点击穿透 |

### 3.2 三层架构划分

| 层 | 目录 | 职责 | 典型类型 |
| --- | --- | --- | --- |
| 系统层 | `system/` | 与 Windows 平台能力交互：热键、显示器、剪贴板、窗口特效 | `Win32`、`Clip`、`SystemEvents` |
| 核心层 | `core/` | 与界面无关的业务逻辑与数据：状态、收藏、收集、去重、更新 | `StateStore`、`Gallery`、`TextCollection`、`CapturePipeline`、`ImageContent`、`UpdateChecker` |
| 界面层 | `ui/` | 所有可见窗口与控件、交互与外观 | `ShelfWindow`、`ShotCard`、`ImageViewer`、`PanelWindow`、`BasketWindow`、`TextsWindow`、`SettingsDialog`、`TrayController` |

- **依赖方向**：`ui → core → system`，`core` 不依赖界面，便于复用与测试。
- **装配枢纽**：`AppController`（`app.cpp`）负责把三层粘合——持有各模块实例、用信号槽连接“界面动作 → 业务处理”，并监听系统剪贴板、全局热键与更新结果。

### 3.3 关键设计点

- **共享条目模型**：`Gallery` 用 `QSharedPointer<CaptureItem>` 让“挂绳”与“收集”两个列表共享同一对象，卡片与内置查看器可安全延长条目生命周期，避免悬空指针。
- **剪贴板防回环**：写回剪贴板时带“图绳自有格式”标记，收集逻辑据此跳过自身写入的回显；同时用像素指纹（SHA-256 采样）做图片去重。
- **原子持久化**：`state.json` 用 `QSaveFile` 原子写入，图片全部复制进程序旁 `data/Captures` 收件夹统一管理。
- **卡片交叠排布**：绳子在容器宽度内按需交叠排布卡片（每张最多推进固定距离），保证整排不超出可视宽度，无需横向滚动；卡片尺寸切换后整条绳子高度同步重算。
- **内置查看器**：`ImageViewer` 为固定尺寸窗口，按同目录图片顺序浏览，滚轮缩放、`0` 复位、放大后可拖动平移，底栏显示文件名与缩放/序号。
- **面板预创建与多屏定位**：启动后空闲时预建图片篮子/文字笔记面板（并预创建原生窗口句柄）；呼出时以鼠标所在屏幕为基准，绳子在该屏展开就贴托板，否则落在该屏右上角。
- **热键自定义与回滚**：`registerToggleHotkey(sequence)` 把 Qt 组合键映射为 Win32 修饰键与虚拟键码，只接受带修饰键的组合；注册失败时提示并回滚到上一个可用热键，避免“设置显示成功却唤不出挂绳”。
- **界面多语言**：界面语言保存在 `state.json` 的 `Language`（默认 `zh_CN`）；启动时若为 `en` 则用 `QTranslator` 加载程序旁 `translations/PicRope_en.qm`，设置中切换语言后自动重启生效。
- **自动清理与上限**：设置「功能」中开启后，图片按挂绳 + 篮子合计计数、文字按笔记条数计数，超过上限时从最早收集的内容开始移除（收件夹内的自有副本移入回收站）；上限调低到低于当前数量时先弹窗确认，实际裁剪在下一次增删图片或文字时执行。
- **设置界面布局**：固定尺寸窗口内左右两栏——左侧分区导航点击跳转、滚动时按位置高亮，右侧内容放进滚动区；各分区收纳进浅色圆角卡片，窗口高度不足时上下滑动。
- **数据备份与恢复**：导出 / 导入通过系统 PowerShell 异步打包与解压，导出时按 zip 体积增长显示进度、完成后在行内提示（不弹窗）；导入覆盖当前设置与数据并提示重启；「恢复默认设置」（位于「其他」分区）只重置设置项，图片、文字笔记与已收集文件保留。
- **存储空间统计**：设置「数据」中按需异步扫描 `data/` 目录，分列图片、文字笔记、配置与其它及总计；勾选自动清理时同时显示当前数量与上限。
- **开机自启**：设置开关读写当前用户注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，安装版与绿色版共用同一状态。
- **应用内更新**：`UpdateChecker` 请求本仓库最新发行版 JSON，按数字段比较版本号，优先选取资源名含 `Setup` 的 exe，下载到临时目录后启动安装程序；启动约 4 秒后静默检查（受 `autoCheckUpdate` 控制，默认开启）。
- **单实例与容错**：用 `QLockFile` 保证单实例，崩溃残留锁可清理；启动失败写 `data/error.log`。

## 四、构建与运行

**环境要求**

- Qt 6（**Widgets + Network** 模块），支持 C++17 的编译器（MSVC / MinGW 均可；MSVC 已开启 `/utf-8`）
- Windows 10 / 11 64 位
- 构建英文界面时需要 Qt Linguist 工具链（`lrelease`）生成 `.qm`（仓库已附带现成的 `PicRope_en.qm`）

**构建步骤**

```bash
# 用 Qt Creator 打开 qt_PicRope.pro，选择构建套件后直接构建运行；
# 或在命令行 qmake + make 构建：
qmake qt_PicRope.pro
make          # MinGW：mingw32-make；MSVC：nmake / jom
```

**翻译**

- 英文界面由 `translations/PicRope_en.ts` 编译得到 `PicRope_en.qm`（`lrelease PicRope_en.ts`）。
- 工程已配置 `TRANSLATIONS` 与构建后复制步骤：`.qm` 会被复制到产物旁 `translations/`，运行时按 `Language` 设置加载；缺少 `.qm` 时界面回退简体中文。

**运行目录约定**

- 状态与配置：程序旁的 `data/state.json`（设置、主题、界面语言、卡片尺寸、不透明度、收起延迟、热键、自动清理开关与图片/文字上限、挂绳与收集路径、文字笔记）
- 图片收件夹：程序旁的 `data/Captures/`（收集与手动导入的图片副本）
- 界面翻译：程序旁的 `translations/PicRope_en.qm`
- 错误日志：`data/error.log`（热键注册失败、更新异常等会记录于此）

**发布、网站与更新**

- 通过 GitHub Releases 提供 Windows 安装包（`*Setup*.exe`）；应用内更新即读取该发行版，下载后自动启动安装程序。
- `docs/` 是配套项目网站（首页 + 使用文档，中英切换），纯静态资源，可直接用 GitHub Pages 等方式托管。

**常用快捷键与操作**

| 操作 | 方式 |
| --- | --- |
| 显示 / 收起绳子 | 默认 `Ctrl+Alt+T`（设置「快捷键」中可改），或单击托盘图标 |
| 区域截图 | `Win + Shift + S`（系统截图工具的默认快捷键，不可在应用内修改；托盘「更多 → 区域截图…」亦可触发），截图结果进入剪贴板 |
| 打开图片 | 双击卡片，用内置查看器（同目录 ← / → 切换、滚轮缩放、`0` 复位、Esc 关闭） |
| 复制 / 编辑 | 单击复制；长按或右键 →「编辑」（系统默认图片编辑器） |
| 图片篮子 | 搜索文件名、右键重命名、打开文件夹、复制到剪贴板、用系统编辑器打开、挂上/取下绳子、双击预览、框选或 Ctrl/Shift 多选、删除 |
| 文字笔记 | 搜索、查看全文、复制、框选多选、「删除所选」 |
| 设置 / 主题 / 语言 | 托盘「设置…」或绳子托板齿轮按钮；六分区跳转，可切主题、调卡片尺寸/不透明度/收起延迟、改热键、开自动清理并设上限、切界面语言（语言切换后重启） |
| 数据管理 | 设置「数据」：查看存储空间明细（点「扫描」）、导出/导入备份（异步、行内显示进度）；「其他」中可恢复默认设置 |
| 托盘管理 | 显示/收起、图片篮子…、文字笔记…、剪贴板图片/文字收集开关、自动弹出（持久化）、新图片自动上绳、设置、「更多」中的区域截图 / 打开收集文件夹 / 全部取下（保留文件）、退出 |
