# qt_PicRope · 图绳（Qt 重构版）
简体中文 | [English](README.en.md)

</div>

> **Qt 二次开发版本**（当前版本 **1.1.2**），源自作者 [Renly1994](https://github.com/Renly1994) 的 [PicRope](https://github.com/Renly1994/PicRope)（Windows 截图暂存与桌面贴图工具）。本仓库使用 **C++ / Qt Widgets** 对原 **C# / WPF** 项目进行重构与二次开发。

**图绳（PicRope）** 是一款 Windows 截图暂存与桌面贴图工具：它把截图自动收集到屏幕上沿的一条“绳子”上，鼠标移到顶部即展开、离开后自动收起。单击图片即可复制，拖入聊天框、文档等目标应用即可取用；双击可用内置查看器放大查看。适合写文档、做教程、整理参考图等场景。

## 一、项目来源与说明

- **原作者仓库（上游）**：<https://github.com/Renly1994/PicRope>（Windows 截图暂存与桌面贴图工具，C#/WPF）
- **本仓库（Qt 二次开发版）**：<https://github.com/2058763315/qt_PicRope>
- **定位**：对原作者 C#/WPF 实现的 Qt 二次开发版本，代码用 C++17 重写，界面与交互逻辑对齐原版，并复用其功能设计（截图收集、绳子、篮子、文字笔记、内置查看器、托盘、多显示器与主题等）。
- 各源文件头部的注释均标注了与原版模块的对应关系（如 `app.h ↔ App.cs DesktopController`、`ui/shelf.h ↔ ShelfWindow`、`core/gallery.h ↔ Gallery` 等），便于对照原版理解设计。
- 应用内更新检查基于本仓库的 GitHub Releases（`2058763315/qt_PicRope`）。

> **说明**：二次开发版本目前聚焦“收集 — 挂绳 — 复制/查看 — 设置/更新”闭环，原版的**内置图片编辑器**与**区域截图标注**（画框/箭头/涂画/马赛克等）尚未在本仓库内实现：当前“编辑”调用系统默认图片编辑器，区域截图则唤起系统截图工具。原版的**桌面贴图（置顶钉图）**当前未编入构建（`ui/pinned.*` 源文件保留）。

## 二、核心功能

| 功能 | 说明 |
| --- | --- |
| **截图收集** | 自动扫描 Windows 截图文件夹的新图片；支持剪贴板图片、剪贴板文字与手动导入 |
| **挂绳暂存** | 新图片按“自动上绳”开关进入绳上（最近 50 张）或图片篮子；卡片多时自动交叠排布以适配可视宽度 |
| **复制与拖拽** | 单击复制图片，拖入目标应用（拖拽为复制语义）；右键可「取下」或「批量取下」 |
| **内置查看器** | 双击图片用内置查看器打开：同目录图片 ← / → 切换、滚轮缩放、放大后拖动平移、Esc 关闭，底栏显示文件名与缩放/序号 |
| **图片篮子** | 按文件名搜索、右键重命名、打开所在文件夹；支持「挂上绳子 / 取下绳子」「删除所选」、双击内置预览、框选或 Ctrl/Shift 多选 |
| **文字笔记** | 收集剪贴板文字（原版称“文字信封”）；支持搜索、查看全文、复制、多选删除，保留原文换行与缩进 |
| **设置界面** | 托盘「设置…」打开，屏幕居中：**外观**（五套主题卡片预览可选）+ **关于**（自动检查更新、当前版本、手动检查更新与下载进度） |
| **应用内更新** | 启动后静默检查 GitHub 最新发行版，发现新版本询问后自动下载安装包并拉起安装（可在设置中关闭自动检查） |
| **全局热键** | `Ctrl+Alt+T` 显示/收起；`Ctrl+Alt+S` 唤起区域截图（组合键可自定义） |
| **托盘控制** | 剪贴板图片/文字收集开关、新图片自动上绳、关闭自动弹出（临时，重启恢复）、设置、打开收集文件夹等 |
| **桌面适配** | 五套外观主题、多显示器选择（跟随鼠标或固定）、顶部自动收起、点击穿透 |

### 3.2 三层架构划分

| 层 | 目录 | 职责 | 典型类型 |
| --- | --- | --- | --- |
| 系统层 | `system/` | 与 Windows 平台能力交互：热键、显示器、剪贴板、窗口特效 | `Win32`、`Clip`、`SystemEvents` |
| 核心层 | `core/` | 与界面无关的业务逻辑与数据：状态、收藏、收集、去重、更新 | `StateStore`、`Gallery`、`TextCollection`、`CapturePipeline`、`ImageContent`、`UpdateChecker` |
| 界面层 | `ui/` | 所有可见窗口与控件、交互与外观 | `ShelfWindow`、`ShotCard`、`ImageViewer`、`PanelWindow`、`BasketWindow`、`TextsWindow`、`SettingsDialog`、`TrayController` |

- **依赖方向**：`ui → core → system`，`core` 不依赖界面，便于复用与测试。
- **装配枢纽**：`AppController`（`app.cpp`）负责把三层粘合——持有各模块实例、用信号槽连接“界面动作 → 业务处理”，并监听系统剪贴板、全局热键与更新结果。

### 3.3 关键设计点

- **共享条目模型**：`Gallery` 用 `QSharedPointer<CaptureItem>` 让“挂绳”与“收集”两个列表共享同一对象，卡片与内置查看器可安全延长条目生命周期，避免悬空指针。
- **剪贴板防回环**：写回剪贴板时带“图绳自有格式”标记，收集逻辑据此跳过自身写入的回显；同时用像素指纹（SHA-256 采样）做图片去重。
- **原子持久化**：`state.json` 用 `QSaveFile` 原子写入，图片全部复制进程序旁 `data/Captures` 收件夹统一管理。
- **卡片交叠排布**：绳子在容器宽度内按需交叠排布卡片（每张最多推进固定距离），保证整排不超出可视宽度，无需横向滚动。
- **内置查看器**：`ImageViewer` 为固定尺寸窗口，按同目录图片顺序浏览，滚轮缩放、放大后可拖动平移，底栏显示文件名与缩放/序号。
- **面板预创建**：启动后空闲时预建图片篮子/文字笔记面板（并预创建原生窗口句柄），消除首次打开时的卡顿。
- **应用内更新**：`UpdateChecker` 请求本仓库最新发行版 JSON，按数字段比较版本号，优先选取资源名含 `Setup` 的 exe，下载到临时目录后启动安装程序；启动约 4 秒后静默检查（受 `autoCheckUpdate` 控制，默认开启）。
- **单实例与容错**：用 `QLockFile` 保证单实例，崩溃残留锁可清理；启动失败写 `data/error.log`。

## 四、构建与运行

**环境要求**

- Qt 6（**Widgets + Network** 模块），支持 C++17 的编译器（MSVC / MinGW 均可；MSVC 已开启 `/utf-8`）
- Windows 10 / 11 64 位

**构建步骤**

```bash
# 用 Qt Creator 打开 qt_PicRope.pro，选择构建套件后直接构建运行；
# 或在命令行 qmake + make 构建：
qmake qt_PicRope.pro
make          # MinGW：mingw32-make；MSVC：nmake / jom
```

**运行目录约定**

- 状态与配置：程序旁的 `data/state.json`（设置、主题、挂绳与收集路径、文字笔记）
- 图片收件夹：程序旁的 `data/Captures/`（收集与手动导入的图片副本）
- 错误日志：`data/error.log`（热键注册失败、更新异常等会记录于此）

**发布与更新**

- 通过 GitHub Releases 提供 Windows 安装包（`*Setup*.exe`）；应用内更新即读取该发行版，下载后自动启动安装程序。

**常用快捷键与操作**

| 操作 | 方式 |
| --- | --- |
| 显示 / 收起绳子 | `Ctrl+Alt+T`，或单击托盘图标 |
| 区域截图 | `Ctrl+Alt+S`（唤起系统截图工具，截图结果进入剪贴板） |
| 打开图片 | 双击卡片，用内置查看器（同目录 ← / → 切换、滚轮缩放、Esc 关闭） |
| 复制 / 编辑 | 单击复制；长按或右键 →「编辑」（系统默认图片编辑器） |
| 图片篮子 | 搜索文件名、右键重命名、打开文件夹、挂上/取下绳子、双击预览、框选或 Ctrl/Shift 多选、「删除所选」 |
| 文字笔记 | 搜索、查看全文、复制、框选多选、「删除所选」 |
| 设置 / 主题 | 托盘「设置…」或绳子托板齿轮按钮；在外观中选择五套主题 |
| 托盘管理 | 剪贴板图片/文字收集开关、自动上绳、关闭自动弹出（临时，重启恢复）、设置、打开收集文件夹 |
