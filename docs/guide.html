使用文档

从安装到日常使用，按顺序读一遍大约十分钟。适用于 1.1.6 版本，Windows 10 / 11 64 位。

目录

快速开始 截图收集 顶部绳子 图片篮子 文字笔记 内置查看器 设置项 快捷键 更新记录

没找到答案？可以到 GitHub 提 issue。

快速开始

图绳由托盘图标常驻运行，界面主要是一条贴在屏幕顶部的绳子。启动后：

  • 托盘区出现图绳图标，右键可打开全部菜单
  • 把鼠标移到屏幕上边缘，绳子自动展开
  • 之后每次截图，图片会自动挂到绳子上

安装版与绿色版

两种包功能完全一致，任选其一：

版本说明
安装版双击 PicRope-1.1.6-Setup.exe 按向导安装，可选开机自启；升级与卸载都会保留 data 目录
绿色版解压 PicRope-1.1.6-win64.zip 后直接运行 PicRope.exe，不写系统目录
图绳使用单实例锁。已经有一个实例在运行时，再次启动会提示「图绳已在运行」，不会有第二个图标出现。

截图收集

图绳不替换系统截图工具，它负责截图之后的部分。目前会从两个来源收集图片：

  • 剪贴板：复制图片、或用 Win Shift S 截图后，图片自动保存并挂上绳子
  • 「屏幕截图」文件夹：系统截图工具存入的图片同样会被收集

同一张图片经多个来源出现时，图绳按图片内容去重，只保留一张，不会重复挂两次。

收集行为可以在托盘菜单里分别关闭：剪贴板收集 · 图片、剪贴板收集 · 文字。

顶部绳子

绳子贴在屏幕顶部边缘，平时隐藏。鼠标移到上边缘时展开，离开后自动收起，也可以通过托盘菜单的显示/收起或快捷键 Ctrl Alt T 手动切换。

卡片操作

单击卡片复制图片；双击用内置查看器打开；右键菜单包含：

菜单项作用
复制图片把图片放入剪贴板
打开图片调用系统默认看图软件打开
保存副本…另存到指定位置
在文件夹中显示在资源管理器中定位文件
编辑…用系统图片编辑器打开
取下 / 取下左侧 / 取下右侧 / 取下其他 / 全部取下从绳子移除卡片，文件仍保留
删除（移入回收站）删除磁盘文件并移入回收站
「取下」只影响绳子上的卡片，源文件不会被删除；需要真正删除文件时用最后一项。

图片篮子

绳子只放当前要用的图片，其余的可以先收进篮子。从托盘菜单打开图片篮子…。

  • 标题栏搜索框按文件名实时筛选，右侧叉号一键清空
  • 鼠标拖动可框选，Ctrl / Shift 点击可多选
  • 右键复制放进剪贴板、编辑用系统默认程序打开；重命名…直接改磁盘文件名，收藏记录与绳子卡片同步更新
  • 挂上绳子把选中的图片送回绳子，取下绳子则相反
  • 底部状态栏显示总数与选中数，左侧打开文件夹直接定位图片目录

文字笔记

复制过的文字也会被收集，从托盘菜单的文字笔记…打开。左侧是列表，选中后在右侧查看全文；支持搜索、多选后一次性复制或删除。

内置查看器

双击绳子上的卡片即可打开，查看器会自动读取同目录下的图片，方便前后翻看。

  • ← → 切换上一张 / 下一张
  • 滚轮以鼠标位置为中心缩放，范围 100% ~ 800%
  • 放大后按住图片拖动平移，按 0 复位到 100%
  • 未放大时按住图片或底部信息栏，可以拖动整个窗口
  • Esc 关闭查看器

设置项

托盘菜单设置…打开。窗口左侧是分区导航（功能 / 快捷键 / 外观 / 数据 / 其他 / 关于），点击即可跳到对应分区，滚动时左侧会自动高亮当前所在分区。

功能

设置说明
鼠标移到屏幕顶部自动弹出挂绳与托盘菜单的自动弹出实时双向同步，状态会保存
剪贴板收集 · 图片与托盘菜单同步；关闭后复制的新图片不再收集
剪贴板收集 · 文字与托盘菜单同步；关闭后复制的新文字不再收集
新图片自动上绳与托盘菜单同步；关闭后新图先收进图片篮子，需要时再挂上绳子
界面语言简体中文 / English，切换后提示重启，重启生效
开机时自动启动图绳绿色版可直接勾选；与安装包写入同一注册表项，安装时勾选的自启也能在这里关闭
自动清理勾选后可分别设置图片与文字笔记的上限，超过上限时自动清理最早收集的内容
图片篮子上限统计所有图片总数（挂绳 + 篮子合计），不是单独的已挂或未挂；默认 200
文字笔记上限文字笔记总数上限，默认 200

把上限改到低于当前已存数量时会先弹窗确认：选「否」取消修改并恢复原值，选「是」才保存新上限。

快捷键

「显示 / 收起挂绳」的热键可以自定义：点进输入框，按下新的组合键即可，默认 Ctrl Alt T。

热键必须包含 Ctrl、Alt、Shift 或 Win 之一；修改后立即生效并保存。若与其它程序冲突，会提示并回滚到上一个可用热键。

栏目中会列出全部快捷键：灰色带锁标记的是系统或查看器内置，鼠标移上去会说明来源，无法在此修改。

外观

内置五套主题：经典 · 银灰、棉麻 · 木夹、奶白 · 轻盈、柔彩 · 日常、石墨 · 金属。切换后界面与卡片风格同步变化。

设置说明
卡片尺寸小 / 中 / 大，改变挂绳上缩略图的大小，切换后立即生效
挂绳不透明度20% ~ 100%，每档 20%；调低后对桌面内容的遮挡更少
收起延迟鼠标离开顶部后 300 / 800 / 1200 / 1500 毫秒自动收起，默认 1200 毫秒

数据

设置说明
存储空间点击整行展开明细，右侧按钮扫描；异步统计图片、文字笔记、配置与其它占用，勾选自动清理时同时显示当前数量与上限
导出数据备份把 data 目录打包成 zip，方便迁移到另一台电脑；导出过程异步进行，界面显示进度与百分比，完成后行内提示「导出完成」，不会弹出窗口打断操作
导入数据备份从备份 zip 恢复设置与数据；导入异步进行，完成后行内提示「导入完成」并询问是否立即重启
打开数据目录直接打开 data 文件夹，查看图片与配置

其他

设置说明
恢复默认设置重置所有设置项，保留图片与文字笔记；可选择立即重启

关于

显示当前版本号，并可手动检查更新。勾选自动检查更新后，启动时会自动查询新版本；发现新版本时可下载并启动安装程序。
